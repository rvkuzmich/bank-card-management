# Система управления банковскими картами

### 📋 Общее описание
RESTful API для управления банковскими картами с системой ролевой аутентификации.
Приложение предоставляет функционал для регистрации пользователей, управления картами, 
выполнения переводов между картами и администрирования системы.

---

## 🚀 Основные функции

### 🔐 **Аутентификация и авторизация** (`AuthController`)
- **Регистрация пользователей** (`POST /api/v1/auth/register`)
    - Создание нового аккаунта с ролью USER по умолчанию
- **Вход в систему** (`POST /api/v1/auth/login`)
    - Получение JWT токена для доступа к защищенным эндпоинтам
- **Просмотр профиля** (`GET /api/v1/auth/profile`)
    - Получение информации о текущем пользователе

### 💳 **Управление банковскими картами** (`CardController`)
- **Создание карт** (`POST /api/v1/cards`) - *только для ADMIN*
    - Создание новых банковских карт
- **Просмотр карт пользователя** (`GET /api/v1/cards`)
    - Получение списка карт с пагинацией и фильтрацией
- **Блокировка карт** (`POST /api/v1/cards/{cardId}/block`)
    - USER: создание запроса на блокировку
    - ADMIN: мгновенная блокировка карты
- **Подтверждение блокировки** (`POST /api/v1/cards/{cardId}/approve-block`) - *только для ADMIN*
    - Подтверждение запросов на блокировку от пользователей
- **Активация карт** (`POST /api/v1/cards/{cardId}/activate`) - *только для ADMIN*
    - Активация ранее заблокированных карт
- **Просмотр баланса** (`GET /api/v1/cards/{cardId}/balance`)
    - Получение текущего баланса карты

### 💸 **Денежные переводы** (`TransferController`)
- **Перевод между картами** (`POST /api/v1/transfers`)
    - Перевод средств между собственными картами пользователя
- **История переводов** (`GET /api/v1/transfers/history`)
    - Просмотр истории транзакций с пагинацией

### 👥 **Администрирование пользователей** (`UserController`) - *только для ADMIN*
- **Список всех пользователей** (`GET /api/v1/users`)
    - Получение списка пользователей с пагинацией
- **Изменение роли пользователя** (`PATCH /api/v1/users/{userId}/role`)
    - Изменение роли (USER/ADMIN) для любого пользователя
- **Блокировка пользователя** (`POST /api/v1/users/{userId}/disable`)
    - Отключение доступа пользователя к системе
- **Разблокировка пользователя** (`POST /api/v1/users/{userId}/enable`)
    - Восстановление доступа пользователя

---

## 👥 Роли пользователей

### **USER** (Обычный пользователь)
- Регистрация и авторизация
- Просмотр своего профиля
- Просмотр своих карт
- Запрос на блокировку карт
- Переводы между своими картами
- Просмотр истории переводов
- Просмотр баланса карт

### **ADMIN** (Администратор)
- Все права USER
- Создание новых банковских карт
- Мгновенная блокировка карт
- Подтверждение/отклонение запросов на блокировку
- Активация заблокированных карт
- Просмотр всех пользователей
- Изменение ролей пользователей
- Блокировка/разблокировка пользователей

---

## 🔒 Безопасность
- **JWT-аутентификация** с временными токенами
- **Ролевая авторизация** через Spring Security
- **Валидация входных данных** через Jakarta Validation
- **Защита от несанкционированного доступа** к чужим данным
- **HTTPS рекомендация** для продуктивной среды

---

## 📊 Особенности
- **Пагинация** для всех списковых эндпоинтов
- **Фильтрация** карт по различным параметрам
- **Единый формат ответов** через `ApiResponseDto`
- **Логирование действий** на уровне сервисов
- **Валидация бизнес-логики** (проверка баланса, статусов карт и т.д.)
- **Гибкая система блокировки карт** с подтверждением от администратора

---

## 🛠 Технологический стек
- **Backend**: Java 17, Spring Boot 3.2.5, Spring Data JPA
- **Security**: Spring Security + JWT
- **Database**: PostgreSQL
- **Migrations**: Liquibase
- **Validation**: Jakarta Bean Validation
- **Containerization**: Docker, Docker-Compose
- **Documentation**: SpringDoc OpenAPI
- **Build Tool**: Maven


Это приложение предоставляет полный цикл управления банковскими картами от регистрации 
пользователей до сложных операций с переводом средств, с четким разделением прав доступа между 
обычными пользователями и администраторами системы.

Для запуска приложения используется команда docker-compose up --build -d
